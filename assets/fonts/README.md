# IBM Plex Sans

Unmodified TrueType fonts from the [official IBM Plex repository](https://github.com/IBM/plex/tree/master/packages/plex-sans/fonts/complete/ttf), retrieved 2026-11-08:

- `IBMPlexSans-Regular.ttf` — interface and body text
- `IBMPlexSans-SemiBold.ttf` — brand and table headings
- `IBMPlexSans-Italic.ttf` — italic text support
